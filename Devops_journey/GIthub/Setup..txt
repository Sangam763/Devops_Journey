Prerequisites & GitHub Account SetupCreate a GitHub Account: Go to GitHub Signup and register for an account.Create a Remote Repository:Log in to GitHub and click the + icon in the top-right corner $\rightarrow$ New repository.Name your repository (e.g., my-project).Check Add a README file.Click Create repository.2. AWS Linux Instance Setup & Git InstallationRun these commands in your Ubuntu/Debian terminal to update packages and install Git:Bash# Update package lists
sudo apt update

# Install Git
sudo apt install -y git

# Verify installation
git --version

3. Global Identity ConfigurationSet the name and email linked to your commits:Bash# Set your display name
git config --global user.name "Your Name"

# Set your email (use your GitHub account email)
git config --global user.email "your.email@example.com"

# Verify settings
git config --list
4. Project Initialization & First Push to GitHubConnect your local repository to the GitHub repository you created:Bash# Create and enter your project folder
mkdir my-project
cd my-project

# Initialize a local Git repository
git init

# Set the primary branch name to 'main'
git branch -M main

# Add your GitHub repository as the remote destination
# Replace <your-username> and <repository-name> with your GitHub details
git remote add origin https://github.com/<your-username>/<repository-name>.git
remote set-url origin https://<githubtoken>@github.com/<your-username>/<repository-name>.git 
# Create a sample file and stage it
echo "# My Project" > README.md
git add README.md

# Commit the changes locally
git commit -m "Initial commit"

# Push your code to GitHub
git push origin main
